# ShareCycle

A blockchain-powered charity and donation marketplace for students.

## Problem

Students struggle to afford educational materials while many usable items remain unused after graduation.

## Solution

ShareCycle allows verified donors to donate educational items securely using Stellar Soroban smart contracts.

## Stellar Features Used

- Soroban Smart Contracts
- XLM
- Trustless transaction records
- On-chain donation tracking
